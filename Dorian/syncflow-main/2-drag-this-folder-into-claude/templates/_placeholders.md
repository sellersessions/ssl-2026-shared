# `report.html` placeholder catalogue

Two templates ship in the bundle:

- **`templates/dashboard-artifact.html`** *(primary path — emitted as a Claude artifact)* — React + Tailwind-CDN, interactive 11-page navigation in Claude Desktop's artifact panel.
- **`templates/report.html`** *(secondary — static print-ready)* — self-contained HTML with **79 unique `{{var}}` placeholders** and a single inlined `<style>` block. No JavaScript dependencies. Used in tier-2 disk persistence or when the delegate explicitly asks for a printable static file.

Both templates use the same placeholder set documented below; they differ only in interactivity and dependencies.

This file documents every placeholder, what it means, and where it appears in the report. **Generated by `scripts/build-templates.mjs`. Do not edit by hand — regenerate via `npm run build:templates`.**

## How syncflow fills the template

1. Read all four brain MDs (`business.md`, `team.md`, `stack.md`, `goals.md`)
2. Read `templates/report.html`
3. For every `{{var}}` listed below, substitute the corresponding value from the brain
4. For repeating sections (modules, replacement rows, summary cards, glossary, etc.), the rendered HTML contains **one example block** with `{{vars}}` inside. syncflow treats it as a row template and **duplicates the surrounding DOM element** per item from the brain, with each copy filled from the brain. Generation rules in the "Loop blocks" table below.
5. Hand the filled HTML to `emit-roadmap-artifact` for Claude artifact emission. *(Tier 2 only: also writes a copy to `output/<brand>/roadmap.html`.)*

> **Substitution scope.** Only substitute inside the `<body>` or page content sections. Don't touch `<head>` (the inline CSS and font links must remain).

## Tone-specific variations

When duplicating loop blocks, syncflow must apply the right Tailwind / inline-CSS classes per tone. Reference table:

| Concept | Tone | Pill class |
|---|---|---|
| Savings (green / positive) | `savings` | `bg-savings-bg text-savings` (also: card bg `#E1F5EB`) |
| Owned (blue) | `owned` | `bg-owned-bg text-cobalt-700` |
| Rented (red / cut) | `rented` | `bg-rented-bg text-rented` (also: row bg `#FFE9EB`) |
| Warn (amber / blind-spot) | `warn` | `bg-warn-bg text-warn` |
| Neutral | `neutral` | `bg-paper-2 text-graphite` |
| Blue (informational) | `blue` | `bg-cobalt-50 text-cobalt-700` |

## What `_placeholders.md` is and isn't

- **Is** the contract between syncflow (the agent) and the static template
- **Is** maintained automatically by `scripts/build-templates.mjs` (regenerated every time the template is rebuilt — but the descriptive copy here is hand-curated)
- **Isn't** a list of every string in the template. Static text (the manifesto cards' labels, the section headings on rented vs owned, "What it replaces · rented → owned", etc.) lives in `report.html` directly and doesn't need substitution
- **Isn't** the system prompt — that lives in `00-syncflow-system-prompt.md` (Phase 4c) and tells syncflow *how* to use this template
