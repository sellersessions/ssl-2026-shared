Appendix.

Glossary
Owned
A capability your business owns the data, schema, and workflow for. Compounds over time.
Rented
A SaaS subscription. Stops working the moment payments stop or vendor pivots.
Glue-human
A person paid to copy data between tools that don't talk to each other.
CSV moment
A recurring "export from one tool, edit, import to another" ritual. Visible tax of stack sprawl.
Module
A discrete owned-system build (e.g. Demand Planning, Branded Documents) that retires specific rented surface.
Claude Cowork
Claude's project workspace where syncflow lives. You're (probably) reading this PDF because someone ran a syncflow session in Cowork. The project keeps the brain, the modules, and the per-module build plans together in one shared canvas.
Claude Code
Anthropic's command-line developer tool. The "tech-savvy operator" path uses Claude Code on a laptop, with the syncflow build plan + per-module CLAUDE.md as the input.
MCP
Model Context Protocol — how Claude connects to your tools (ClickUp, Supabase, n8n, Slack, etc.). Each MCP is a one-time setup; once wired, Claude reads/writes to that tool natively without copy-paste.
Brain (brain.json)
A snapshot of every fact captured about your business in the syncflow interview. Drag it back into a fresh Cowork project to resume from where you left off, or hand it to your tech lead so they don't have to re-explain the company.
