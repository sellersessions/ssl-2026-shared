# Question Framing, Sample Size & Significance

Bad question wording invalidates a test. Florence applies these rules
**every** time she writes a poll question.

## The 7 question rules

1. **Singular** — one question tests one thing. *"Which is clearer
   and more trustworthy?"* is two questions.
2. **No superlatives** — *"which is best"* nudges shoppers toward the
   safe answer. *"Which would you click on?"* is behavioural.
3. **Purchase-intent language** — *"which would you be more likely to
   click/buy"* not *"which do you prefer."* Preference and behaviour
   diverge.
4. **Don't explain the test** — *"we're testing a new image"* biases
   toward novelty. The shopper should not know which option is yours.
5. **Match question to context** — CTR test refers to search
   behaviour (*"you're browsing Amazon for X"*); CVR test refers to
   buying intent.
6. **No loaded adjectives** — *"which looks more professional"* tells
   the shopper what to value.
7. **Never start with the brand name** — speak to the category, not
   the brand. Recruiting the right mindset matters before the shopper
   sees variants.

## Sample size

| Test | Respondents per option | Notes |
|---|---|---|
| Default rule | **50 per option** | Consistent rule of thumb across all test types |
| 5-option Image Split | 250 for full read | Can start at 100–150, top up if no clear winner |
| Search Simulation | 100+ minimum | Per Main Image Sequencer Step 2 |
| Pinion Ask open-ended (objection mining) | 100 shoppers | Step 2 of CVR workflow |

## Statistical significance thresholds

ProductPinion returns a confidence number after every test. Florence
interprets:

| Confidence | Meaning | Florence's action |
|---|---|---|
| **50%** | Coin flip. Variants are too similar. | Recommend bigger swings, not more respondents. "No result IS a result." |
| **60–69%** | Judgment call zone. | Top up respondents on the same test, OR make variants more distinct, OR rerun with bigger swings. |
| **70%+** | Repeatable enough to act on — 70%+ chance the next run picks the same winner. | Ship, then move to the next test. |
| **95%+** | Easy ship. | Use as flagship case-study confidence (e.g. Invisaband 98% on a 5-way name test). |

## When Florence sees no clear winner

Don't keep adding respondents indefinitely. After one top-up, if it's
still under 70%, the variants themselves are the problem — go back to
concept creation with bigger swings.

## What "no result is a result" actually means

A null result tells the seller their proposed variation isn't moving
the needle. That's directly actionable: stop investing in that
direction, try a more distinct concept. It is **not** an excuse to
relaunch the same test until noise gives the answer the seller wants.
