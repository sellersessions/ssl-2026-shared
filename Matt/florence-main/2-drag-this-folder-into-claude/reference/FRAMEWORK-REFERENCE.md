## CORE PRINCIPLES (Non-Negotiable)

1. **Show Me, Don't Tell Me** — Lead with photography that visually demonstrates the benefit. If you have to explain with text, the image is failing.
2. **Photography First, Copy Second** — 70%+ photography, copy is 3-6 words per callout (labels, not explanations).
3. **Clean, Focused, Scannable** — One message per image. Communicate in under 2 seconds. Billboard test.
4. **Right Demographic** — Person in image must match target customer.
5. **Mobile-First** — 80%+ browse on mobile. All text legible at phone size (24pt+ equivalent). Test at 400x400px.
6. **Visual Consistency** — Same fonts, colors, style across gallery + A+.

---

## RESEARCH-TO-CONTENT DECISION RULES

- If benefit appears in 30%+ of reviews → MUST be photographically demonstrated
- If complaint is repeated → an image must preempt it
- If high-volume keyword describes a benefit not shown → CVR leak, fix immediately
- If every competitor shows something you don't → table stake, match it
- If no competitor shows something customers care about → differentiation opportunity (only after basics)

## METRIC-TO-ACTION MATRIX

| Signal | Diagnosis | Action |
|--------|-----------|--------|
| Low CTR | Main image doesn't stop scroll | Redesign main image |
| High CTR + Low CVR | Listing doesn't convert clickers | Fix listing images / A+ |
| High Returns | Product doesn't match expectations | Fix color accuracy, size representation |
| Negative reviews re visuals | "Looks different" / "Smaller than pictured" | Add scale references, honest photography |

## MAIN IMAGE (Slot 1)

### Hard Requirements
- White background RGB 255,255,255
- Product fills 85%+ of frame
- No text, logos, watermarks, badges
- Min 1000px (2000x2000 recommended)
- Actual product only, no props/hands/lifestyle

### Creative Techniques
- Wide-angle for depth/dimension, dramatic angles (slightly below)
- Show product + premium packaging together
- On-product elements: tags, labels, stickers, bands
- Ensure compelling packaging text is legible at thumbnail
- Soft shadows, slight reflections, depth of field

### Scoring (1-10, 6 Dimensions)
| Dimension | Description |
|-----------|-------------|
| Fidelity | Accurate colors, materials, proportions |
| Background | Pure #FFFFFF |
| Scroll-Stop | Impossible to ignore in search grid |
| Compliance | Fully compliant with Amazon rules |
| Creative | Optimized angle/crop/presentation |
| Quality | Studio-quality photography |

Pass: Average 7+ with no dimension below 5.

### Auto-Fail
- Product too small in frame
- Flat front-facing catalog shot
- Dull lighting
- Cluttered multi-pack
- Poor cutout with visible artifacts
- Light product blending into white

## LISTING IMAGES (Slots 2-7)

### NO TEMPLATE — Research Decides

### Slot Priority
- **Slots 2-3**: Conversion images. Strongest content. If only optimizing two, optimize these.
- **Slots 4-6**: Supporting (specs, comparisons, details)
- **Slot 7**: Last touchpoint before buy. Must close strong. Never waste.

### Image Types (Priority Order)
1. **Benefit Photography** — Product in situation where benefit is self-evident
2. **Lifestyle** — Real usage context, correct demographic
3. **Product Detail** — Close-ups of materials, textures, construction + scale reference
4. **Infographic** — Specs that can't be photographed. 3-5 callouts max. Photography dominates.
5. **Comparison** — Side-by-side. Never name competitors. Generic labels.
6. **Social Proof** — Awards, certifications, UGC-style

### Assessment (4 Layers)
1. **Design & Readability** — Mobile legible? Single message? Product prominent?
2. **Slot Effectiveness** — Right content in right position? Strongest in slots 2-3?
3. **Research Alignment** — Addresses what customers search, ask, complain about?
4. **Conversion Impact** — Keep / Revise / Replace verdict per image

### Optimization Priority Order
1. Remove conversion barriers (unreadable text, misleading content)
2. Address high-volume keyword gaps (benefit searched but not shown)
3. Answer unanswered customer questions
4. Match competitive table stakes
5. Amplify purchase triggers
6. Create differentiation (only after basics)

## A+ CONTENT

### Two-Half Architecture
**Top Half (Segments 1-3)**: Capture & Convert
- Photography-forward, emotionally compelling
- Segment 1 = visually striking hero (NOT text wall)
- Builds on listing images, doesn't repeat them
- NOT for specs, FAQs, or secondary details

**Bottom Half (Segments 4+)**: Inform & Reassure
- For deep-scrolling interested shoppers
- Answer secondary questions, FAQs, specific details
- Handle objections (size, complexity, durability, value)
- Visual FAQ section

### Rules
- Don't repeat listing images — expand the story
- Full-width > side-by-side on mobile
- One message per segment
- Scannable in 15-20 seconds on mobile without reading
- No carousels (friction)
- Alt text: pack with product name, keywords, benefits, use case (indexed by Amazon search + Rufus)

### Common Mistakes
1. Text-heavy segments
2. Repeating listing images
3. Leading with specs (bottom half only)
4. No visual hierarchy
5. Ignoring bottom half
6. Brand Story as filler

4. Generic Stock Photography
