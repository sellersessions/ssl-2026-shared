Architecture · Secrets 17 / 19

How keys are handled.

Resolution order: Cowork connector → OS keychain → .env → workshop default → fail with helpful message.

1 · Cowork connectors

Slack, Notion, Calendar, Drive, GitHub. OAuth handled by Anthropic. Florence never sees raw tokens.

2 · OS keychain

Mac Keychain, Windows DPAPI, libsecret. Wrapped by a local florence-keys MCP. Keys never written to disk in plaintext.

3 · .env file

Last-resort fallback. Gitignored. Used in CI or when keychain unavailable.

4 · Workshop default

$500-cap shared keys ship in .env.example. Nothing is blank on day one. Retired the Monday after.

SP-API splits two ways: shared workshop read-only token (allow-listed to demo ASINs) for the workshop, then /florence-spapi-link at home for own data.
